# HospitalManagement

Hospital Management PowerBi project

Developed an interactive Hospital Management Dashboard in Power BI to analyze and monitor key hospital performance metrics. The dashboard provides insights into patient admissions, discharges, bed occupancy, doctor performance, appointment trends, revenue, and departmental efficiency. It includes dynamic filters, KPIs, charts, and drill-through reports, enabling hospital administrators to make data-driven decisions and improve operational efficiency. The project demonstrates skills in Power BI, Power Query, DAX, data modeling, and interactive dashboard design
